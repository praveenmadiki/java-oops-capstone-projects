# ☕ Java OOP Capstone Projects

A collection of practical **Java projects**, with each project designed to demonstrate and strengthen a specific **Object-Oriented Programming (OOP)** concept.

Instead of learning OOP concepts only through theory, this repository applies each concept to a small real-world problem.

## 🎯 Purpose

The goal of this repository is to build a strong understanding of Java OOP by implementing practical projects based on individual concepts.

Each project focuses on a particular concept and gradually increases in complexity.

## 📚 Projects

| # | OOP Concept | Project |
|---|---|---|
| 01 | Encapsulation | 🏦 Bank Account Management |
| 02 | Inheritance | 🚗 Vehicle Management System |
| 03 | Polymorphism | 💳 Payment System |
| 04 | Abstraction | 🏧 ATM System |
| 05 | Interfaces | 🔔 Notification System |
| 06 | Composition | 🛒 Shopping Cart System |
| 07 | Exception Handling | 🏥 Hospital Management |
| 08 | Collections | 📚 Library Management |
| 09 | OOP + Collections | 🏨 Hotel Management |
| 10 | OOP + Multiple Concepts | 🏢 Employee Management System |

## 🧠 Learning Approach

Each project follows this approach:

```text
Learn the concept
      ↓
Understand the problem
      ↓
Design classes
      ↓
Implement the concept
      ↓
Add validation
      ↓
Test the application
      ↓
Refactor the code
      ↓
Document the project
```
